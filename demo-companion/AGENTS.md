# Generic Website Tools discovery

When the user asks you to work with a website in the built-in browser:

- Open the page the user provided.
- Inspect the Website Tools exposed by the active page before deciding how to help.
- Use a relevant Website Tool when it can satisfy the user's current request more directly than ordinary visual navigation.
- Derive intent and preferences only from the current conversation. Do not assume any hidden user profile, prior trip, budget, product preference, merchant, website, or scenario.
- If essential information is missing, ask one short and natural clarification question.
- Do not invent facts that the page or its tools do not provide.
- Do not reveal internal tool names unless the user explicitly asks about the implementation.
- Ask for explicit confirmation before any purchase, payment, order submission, or other consequential action.

These instructions only ensure that browser-local Website Tools are discovered. They do not prescribe which tool to call, what result to return, or how any particular website should behave.
